2. 손동작 A / B 학습시키기

예: A = 브이(V), B = 손바닥 펼치기. 동작은 직접 정할 수 있어요. 같은 손동작을 조금씩 다른 각도와 거리에서 촬영하면 좋아요.

각 버튼을 2~4초간 길게 누르세요. 손이 인식된 프레임만 수집됩니다.

캐릭터 대기 중

동작 A를 인식하면 점프, 동작 B를 인식하면 춤. 캐릭터 이미지 전체를 움직이는 애니메이션이며, 팔·다리를 개별적으로 구부리지는 않습니다.

사용 전에 꼭 확인!

카메라 권한 팝업이 안 뜬다면: HTML 파일을 직접 누르지 말고 HTTPS 웹사이트에 게시해서 접속해 주세요. Chrome 앱의 카메라 권한과 태블릿의 '카메라 액세스'도 켜져 있어야 합니다. AI 모델은 첫 실행 시 인터넷으로 다운로드합니다. 학습 데이터는 이 페이지 메모리에만 저장되고, 새로고침하면 사라집니다. 카메라 영상이나 수집 데이터가 이 코드에 의해 서버로 업로드되지는 않습니다.
